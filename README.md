# Portfolio

Static portfolio site (HTML/CSS/JS, no build step).

## Run locally
    python3 -m http.server 8000   # then open http://localhost:8000

## Edit
- Projects: the `projects` arrays in `script.js`
- Images, videos, audio and the font live in `assets/`
- Colors/type: CSS variables in `style.css`

## Deploy
Push to GitHub, then Settings → Pages → deploy from `main` / root. Or import into Vercel/Netlify.
